# 公式總表

2026-09-14 依 Sites v82 程式整理，非新核准 SOP。來源以 `../cabinet-ai-demo/app/sop.ts`、`face-machining.ts`、`drawer-rules.ts`、`hinge-rules.ts`、`quantity-rules.ts` 為主；差異見 [STATUS](STATUS.md)。

## 符號與條件

W＝單桶外寬；H＝桶身外高（不含另段腳高／留空）；D＝桶深；G＝單組抽屜格寬的尺寸基準（不是已扣側板的淨寬）；F＝固格中心線位置；N＝數量。全表單位 mm，cm×10。多數輸出以四捨五入至整數且不小於零處理；不明尺寸不能當成可下料的零。

以下為標準板 18、背板／抽底 8。非標準厚度必須連同已確認扣數 profile 保存，不能只換板厚卻默認標準扣數適用。

## 抽屜（維持舊公式）

中心線邊界數 c=0/1/2，扣數 b=99−9c，即99/90/81。

| 項目 | 公式 |
| --- | --- |
| 外抽前後牆完成寬 A | G−b |
| 內抽前後牆完成寬 A | G−b−50 |
| 外抽深 L | 在300、350、400、450、500中選≤D−29的最大值；不足300不產生可用規格 |
| 內抽深 | 外抽L−50；若<300則不產生可用規格 |
| 抽牆高 h | 完成屜頭高≤200→100；201–239→120；≥240→180；缺屜頭高不另猜 |
| 前後抽牆 | h×A，每抽2片 |
| 邊抽牆 | h×抽深，每抽2片；側邊包前後 |
| 抽底 | (A+10)×(抽深−26)，厚8，每抽1片 |
| 內抽抽補板 | 120×(F−27)，厚25，每內抽4片；F−27=F−18−9 |
| 屜頭 | (G−3)×完成屜頭高，每抽1片，現有程式厚18；任一抽屜無法產生一片屜頭即阻擋完整料單 |
| 並排N欄所需中立 | N−1；不可由上下抽總數推欄數 |

例：G=400、完整側板兩側，舊下料式 A=400−99=301；抽底第一邊311；屜頭寬397。先前討論總抽寬400−18−18−13−13=338，再扣兩片18得302，與舊式301相差1；使用者後續要求「抽屜照舊」，本次不改成302。

**明確衝突：** R67舊提示寫「>200用180」，但實際 helper 與數量規則包含201–239用120；上表忠實記錄現有計算器，不冒稱使用者本輪已重新確認。

## 門板

- 開口基準：單門寬=開口寬÷片數−3；門高=開口高−（含底部30才扣30）−4。2.4／24mm只提示有斜把，不扣門高。
- 完成尺寸基準：直接用完成寬×完成高，不重扣4。
- 純數字「門N」：提示規則要求名義門寬N−2；這是前段辨識／正規化規則，不是 `calculateSop` 對任意文字自動算的通用解析器，需逐路徑驗證。
- 不再判斷24屬於含縫、另列或疊櫃抬高；有標示即確認斜把，無標示仍檢查斜把空隙。門片圖面證據、片數、必要尺寸或加工數矛盾時才暫停該組門料／五金，保留已鎖定片數。
- 假門板：要求保留，但專用類型與公式支援尚需稽核，不能假定全部當可開4E門加鉸鍊。

## 踢腳與輸出

現場長S≤0不列；0<S≤2800列120×2800一支；S>2800先列floor(S/2800)支標準料，餘r=S%2800若>0，再列120×min(2800,r+500)一支。例5900→2800兩支＋800一支。

板料合併鍵＝立面＋品項＋規格＋厚度；五金＝立面＋品項＋單位。板料按品項、第一尺寸降冪、第二尺寸降冪排列，備註保留。來源全量規則另存 [SOURCE-RULES](SOURCE-RULES.md)，不能只看此摘要改寫未知特殊結構。
